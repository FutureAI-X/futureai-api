# Markdown 文档写作规范

本规范用于统一 Markdown 文档的写法，可直接复制到任意项目中作为写作与审校依据，也适合作为 AI 编写文档时的指令。

全文与具体项目无关。示例均为通用示例，套用时替换为项目自身的命令与名词即可。

## 1 总则

### 1.1 以读者要完成的事为准

动笔前先明确读者是谁、他要做什么，全文只服务这个目的。

一句可操作的判断法：**删掉这句话，读者还能不能做对？会不会因此踩坑？**

- 能 → 删。
- 不能 → 留，并压到最短。

按这条筛，被删掉的多是「讲机制」的句子——读起来专业，但不改变任何操作。

| 可以删的句子 | 为什么 |
|---|---|
| 「该命令内部先读取配置，再合并环境变量」 | 读者只需知道何时运行它，不需要知道内部顺序 |
| 「该文件在构建阶段被解析」 | 读者只需知道"执行下一步之前它必须存在" |
| 「该现象由虚拟化组件的端口保留造成」 | 知道成因也改变不了修复命令 |

**唯一例外是排查章节。** 那里机制就是诊断手段——读者正是靠「配置合并只读取引用行上方定义的变量」去定位问题。这类必须保留。

### 1.2 同一条警告只说一次

在**动手的那一步**完整写一次，排查章节用一句指回去：

> 详见 3.3 节第 3 条

不要把同一段理由在多个章节重述。同一条警告出现在三处，是文档显得啰嗦的主因。

### 1.3 操作与参考分开

把「按顺序执行的步骤」和「按需查阅的资料」分到不同章节，步骤章节内部不插入参考资料，读者才不必读无关内容。

可用的骨架：

| 章 | 性质 |
|---|---|
| 安装 / 搭建 | 按顺序执行，步骤之间有依赖 |
| 日常使用 | 常用流程 |
| 故障排查 | 按现象查 |
| 配置 / 参数参考 | 查阅，非步骤 |

## 2 语体

用书面语、第三人称、完整句。

- 不用口语词：~~跑起来~~ → 运行；~~卡住了~~ → 失败；~~搞定~~ → 完成。
- 不用表情符号，提示改为 `> **注意**：`。
- 不用感叹语气，不用「我们」。
- 一句讲一件事，不要将几个意思挤进一个长句。

| 不要 | 改为 |
|---|---|
| 把服务跑起来 | 启动服务 |
| 卡住了看下面 | 失败时参见 3.1 节 |
| 三条原因长得都像「密码错」 | 以下三种原因的现象均表现为「密码错误」 |
| 或者临时绕过 | 亦可临时绕过 |

## 3 代码块

### 3.1 一个代码块只放一条命令

读者点一次复制按钮，就应拿到一条可直接执行的命令。

- 不把多条命令堆在一个块里。
- 不在行尾写 `#` 注释——复制出来还得手动删。

说明写在代码块**外面的引语**里。

反例：

```bash
npm run build    # 构建
npm test         # 测试
```

改为：

构建：

```bash
npm run build
```

测试：

```bash
npm test
```

### 3.2 例外：程序输出

示例输出不是命令，没有可复制的内容，允许多行。这类块不标语言（不写 `bash`），以便与命令块区分。

## 4 表格

### 4.1 表格必须有引语

表格不能直接跟在段落或标题后面悬着，前面要有引出它的句子。

反例——表格悬空：

```markdown
### 1.1 依赖

| 软件 | 版本 |
```

改为：

搭建前应确认以下软件的版本：

| 软件 | 版本 |
|---|---|
| Node.js | ≥ 20 |

### 4.2 不用「表 1」「表 2」

不给表格加编号题注。正文引用改用「如下」「见下文」，或直接复述，不要写「见表 2」。

### 4.3 行数多时按主题分组

一张大表按读者会问的问题拆开，各组加小标题。参数参考表可按「必填 / 存储 / 服务 / 限额」等维度分组。

## 5 章节与引用

- 标题层级用 `1` / `1.1` / `1.2.1`，不用「一、二、三」。
- 交叉引用统一写「详见 3.3 节第 3 条」。
- **改动章节编号后，必须同步修改其他文档中指向它的引用。** 多篇文档互相引用小节号是常态，编号重排会让引用一并失效。

## 6 文件格式

- 行尾统一用 LF。Windows 上的编辑器与工具常默认写成 CRLF，提交前需确认。
- 不用 BOM。
- 文档之间的链接用相对路径。
- 若仓库有 `.gitattributes`，按其规定设置 Markdown 的行尾。

## 7 提交前自查

- [ ] 每句话都通过了「删掉它读者还能做对吗」
- [ ] 同一条警告全文只完整出现过一次
- [ ] 每个命令代码块恰好一行、无行尾注释
- [ ] 每张表格都有引语
- [ ] 无「表 N」编号，无表情符号
- [ ] 章节编号改动后，其他文档中的引用已同步
- [ ] 行尾为 LF
