# gpt-image-2-ext

## 1 概览

APIMart 图像模型。上游模型名为 `gpt-image-2`，同时兼容别名 `gpt-image-2-ext`，两者等价。平台模型名以管理端配置为准，`model` 字段需与之一致。通用请求与响应格式见 [图像生成](README.md)。

模型能力如下。

| 项目 | 值 |
|---|---|
| 平台模型名 | `gpt-image-2-ext` 或 `gpt-image-2`，以管理端配置为准（上游模型名 `gpt-image-2`，`gpt-image-2-ext` 为兼容别名） |
| 参考图 | 支持，最多 15 张 |
| `size` | 15 种画幅比例，或满足约束的像素尺寸；默认 `16:9` |
| `resolution` | `1K`、`2K` 或 `4K`，默认 `1K` |
| 输出数量 | 1 张 |
| 生成方式 | 异步提交，平台轮询上游任务 |

## 2 请求字段

通用字段的含义见 [图像生成](README.md#2-请求字段)。本模型的字段约定如下。

| 字段 | 必填 | 说明 |
|---|---|---|
| `model` | 是 | 平台模型名，如 `gpt-image-2-ext` 或 `gpt-image-2` |
| `prompt` | 是 | 提示词，去除首尾空格后不能为空 |
| `size` | 否 | 画幅比例（如 `16:9`）或像素尺寸（如 `1024x1024`），默认 `16:9` |
| `resolution` | 否 | `1K`、`2K` 或 `4K`，默认 `1K` |
| `image_urls` | 否 | 参考图 URL 数组，最多 15 张 |
| `image_ids` | 否 | 参考图 file_id 数组，优先级高于 `image_urls`，最多 15 张 |

## 3 参数限制

各参数的约定如下。

| 参数 | 限制 |
|---|---|
| `size` | 比例：`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21`；像素：宽高为 16 的倍数、宽高比 1:3~3:1、单边 ≤3840、总像素 ≤3840×2160；不支持 `auto` |
| `resolution` | `1K`、`2K`、`4K`，平台标准值为大写；小写输入会被归一化 |
| `image_ids` | 去重后最多 15 张 |
| `image_urls` | 去重后最多 15 张 |
| `n` | 平台固定为 1，不接受调用方传值 |

`size` 可以传比例，也可以传像素尺寸，由调用方按上表约束自行选择，平台只校验、不做换算。像素尺寸会原样透传给上游；其中超过 `2560×1440` 的部分属于上游实验性支持，平台仍会接受。参考图的校验规则见 [图像生成](README.md#4-参考图)。

`resolution` 在平台侧统一使用大写 `1K` / `2K` / `4K`；发往上游时会自动转成该模型要求的小写 `1k` / `2k` / `4k`，调用方无需关心。

## 4 请求示例

纯文生图：

```json
{
  "model": "gpt-image-2-ext",
  "prompt": "a cat sitting on a windowsill",
  "size": "16:9",
  "resolution": "2K"
}
```

4K 分辨率：

```json
{
  "model": "gpt-image-2-ext",
  "prompt": "星空下的古老城堡",
  "size": "16:9",
  "resolution": "4K"
}
```

指定像素尺寸：

```json
{
  "model": "gpt-image-2-ext",
  "prompt": "a cat sitting on a windowsill",
  "size": "2560x1440",
  "resolution": "2K"
}
```

带参考图：

```json
{
  "model": "gpt-image-2-ext",
  "prompt": "把这张照片变成水彩画风格",
  "size": "1:1",
  "resolution": "2K",
  "image_ids": ["file_1a2b3c4d5e6f"]
}
```

## 5 响应

提交成功时返回：

```json
{
  "code": "success",
  "taskId": "task_e629c5e8a37a614cf2289f650585aae4"
}
```

任务完成后返回 `file_id` 与 `data.url`，格式见 [图像生成](README.md#6-响应)。

## 6 错误与重试

参数错误在扣费前返回 400，包括空提示词、不支持的 `size`、不支持的 `resolution`，以及参考图超过 15 张。

上游明确拒绝受理时返回 HTTP 200 与 `code=fail`。提交结果不确定时，任务状态为 `unknown`，平台会继续确认结果，不会立即退款。

建议携带 `Idempotency-Key`，避免 SDK 超时重试导致重复扣费。

## 7 计费

计费公式见 [图像生成](README.md#8-计费)。本模型按基础积分计费；如果配置了参考图单价，按实际生效字段去重后的张数叠加。

如果按分辨率差异化计价，可在计费规则中配置 `resolution` 条件。平台标准值为大写 `1K`、`2K`、`4K`；匹配时大小写不敏感，历史小写规则仍可命中。
