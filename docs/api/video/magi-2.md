# MAGI-2

## 1 概览

APIMart 提供的参考生视频模型。通用请求与响应格式见 [视频生成](README.md)。

| 项目 | 值 |
|---|---|
| 平台模型名 | `MAGI-2`（以管理端配置为准） |
| 生成方式 | 参考生视频：图片、视频、音频作为参考；没有参考素材时为文生视频 |
| 输出 | 固定 1080p，默认带声音 |
| 时长 | 4–30 秒 |
| 结果 | 平台对象存储的签名地址（转存自 APIMart），带 `file_id` |

`image_ids` 中的图片一律按**参考图**处理，不会被当作首帧或尾帧。需要首帧/尾帧能力时请使用其它模型。

## 2 请求字段

通用字段的含义见 [视频生成](README.md#2-请求字段)。本模型的约定如下。

| 字段 | 必填 | 说明 |
|---|---|---|
| `model` | 是 | `MAGI-2` |
| `prompt` | 是 | 提示词，最多 15,000 字符 |
| `image_ids` | 否 | 参考图片 file_id 数组，最多 10 张 |
| `video_ids` | 否 | 参考视频 file_id 数组，最多 5 段 |
| `audio_ids` | 否 | 参考音频 file_id 数组，最多 5 段 |
| `resolution` | 是 | 固定 `1080P` |
| `duration` | 是 | 输出时长，4–30 的整数秒 |
| `ratio` | 是 | `16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`；不支持 `adaptive` |

## 3 参考素材限制

参考素材只接受平台 `file_id`，校验规则见 [视频生成](README.md#3-参考媒体)。本模型的额外限制如下。

| 素材 | 数量 | 格式 | 时长 |
|---|---|---|---|
| 图片 | 最多 10 张 | JPEG / PNG / WEBP | — |
| 视频 | 最多 5 段 | MP4 / MOV | 每段 2–30 秒，总时长 ≤30 秒 |
| 音频 | 最多 5 段 | WAV / MP3 | 每段 2–30 秒，总时长 ≤30 秒 |

提示词中建议说明每份参考素材的用途（例如“参考视频的运镜、参考图里角色的样貌、参考音频的音乐风格”）。参考素材用于引导生成，不会被直接拼接或原样保留。

## 4 请求示例

```json
{
  "model": "MAGI-2",
  "prompt": "参考图里女孩的样貌和参考音频的音乐风格，生成她在日落海边散步的画面",
  "image_ids": ["file_..."],
  "audio_ids": ["file_..."],
  "resolution": "1080P",
  "duration": 8,
  "ratio": "16:9"
}
```

纯文生视频只需 `model`、`prompt`、`resolution`、`duration`、`ratio`。

## 5 响应

提交成功时返回任务 ID：

```json
{
  "code": "success",
  "taskId": "task_e629c5e8a37a614cf2289f650585aae4"
}
```

任务完成后返回 `taskId`、`status`、`kind`、`file_id` 与 `data`，格式见 [视频生成](README.md#5-响应)。`data.url` 是平台对象存储的签名地址，`data.url_vendor` 是 APIMart 原始地址，`data.url_expires_at` 是签名失效时间；过期后重新查询任务即可获取新签名，不需要重新生成。

## 6 错误与重试

参数、身份、模型配置或参考文件校验错误返回 4xx/503。上游明确拒绝受理时返回 HTTP 200 与 `code=fail`。提交结果不确定时任务保持 `processing`，超过 60 秒提交确认窗口仍无法确认后转为 `failed` 并退款。

建议携带 `Idempotency-Key`，避免 SDK 超时重试导致重复提交。

## 7 计费

本模型按输出秒数计费：

```text
总积分 = duration × 每秒积分（1080P）
```

参考图片、参考音频与参考视频不额外计费。任务失败或取消时全额退回。具体费率以管理端配置为准，也可通过 `/api/pricing` 获取。
