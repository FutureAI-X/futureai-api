# moss-image-sft-1.0

## 1 概览

MOSS 文生图模型（SFT 版本）。通用请求与响应格式见 [图像生成](README.md)。

模型能力如下。

| 项目 | 值 |
|---|---|
| 平台模型名 | `moss-image-sft-1.0` |
| 固定版本 | `moss-image-sft-1.0-2026-10-09`，由管理端配置 |
| 参考图 | 不支持，传入会被忽略 |
| `size` | 像素尺寸，必填 |
| `resolution` | 忽略 |
| 输出数量 | 1 张 |
| 生成方式 | 同步生成，接口仍以异步任务方式返回 |

## 2 请求字段

通用字段的含义见 [图像生成](README.md#2-请求字段)。本模型的字段约定如下。

| 字段 | 必填 | 说明 |
|---|---|---|
| `model` | 是 | `moss-image-sft-1.0`，或管理端配置的 snapshot |
| `prompt` | 是 | 提示词，最多 4000 个字符 |
| `size` | 是 | `宽x高` 像素尺寸，不能传比例 |
| `resolution` | 否 | 忽略 |
| `image_urls` | 否 | 忽略，不计费 |
| `image_ids` | 否 | 忽略，不计费 |

## 3 参数限制

各参数的取值范围如下。

| 参数 | 限制 |
|---|---|
| `prompt` | 非空，最多 4000 个字符 |
| `size` 宽高 | 256–2048 |
| `size` 对齐 | 宽高均为 16 的倍数 |
| `size` 总像素 | 不超过 2097152 |

合法尺寸示例：`1024x1024`、`1280x720`、`1440x1440`、`2048x880`。

`size` 缺省、传比例或超过上述限制时，请求在扣费前返回 400。

## 4 请求示例

```json
{
  "model": "moss-image-sft-1.0",
  "prompt": "雨后的城市街道，霓虹灯倒影，电影感构图",
  "size": "1280x720"
}
```

## 5 响应

提交成功时返回 `{"code":"success","taskId":"..."}`。任务完成后的响应格式见 [图像生成](README.md#6-响应)。

MOSS 任务的 `data.usage` 包含 `generated_images`、`output_width` 与 `output_height`。

## 6 错误与重试

参数错误在扣费前返回 400。上游调用失败时，平台会退还本次扣费，任务状态为 `call_fail`。

MOSS 没有任务查询接口，平台在调用失败后无法找回结果，因此不会自动重试。调用方应使用 `Idempotency-Key` 后重新提交，而不是在超时后直接重发。

## 7 计费

MOSS 当前免费。平台只在管理端配置基础积分，参考图不产生附加费用。

计费公式与规则见 [图像生成](README.md#8-计费)。
