# 文档截图

把截图按下表的文件名放到本目录，文档页会自动显示；未放图片时页面显示占位框，不会出现破图。

| 文件名 | 使用位置 | 建议截图内容 |
| --- | --- | --- |
| `api-key-entry.png` | 创建 API Key · 第 1 步 | 控制台左侧 API Keys 菜单和「新建」按钮 |
| `api-key-name.png` | 创建 API Key · 第 2 步 | 新建 API Key 弹框中的名称输入框 |
| `api-key-created.png` | 创建 API Key · 第 3 步 | 创建成功弹框和复制按钮 |
| `futureai-image-settings.png` | FutureAI Image 接入 · 第 2 步 | 模型管理页面，包含 API Key 与 API 域名输入框 |
| `payment-alipay.png` | 收款方式 · 支付宝 | 支付宝收款码 |
| `payment-wechat.png` | 收款方式 · 微信 | 微信收款码 |
| `contact-qq-group.png` | 联系我们 · QQ 群 | QQ 群二维码 |
| `contact-qq.png` | 联系我们 · QQ | QQ 二维码 |
| `contact-wechat.png` | 联系我们 · 微信 | 微信二维码 |

文件名统一使用小写 `.png`（服务器区分大小写，`.PNG`、`.jpg` 不会生效）。截图建议宽度 1200–1600px，二维码图片 640px 即可；单张体积尽量控制在 500KB 以内。`.gitattributes` 已将 png/jpg 标记为二进制，不会做行尾转换。
