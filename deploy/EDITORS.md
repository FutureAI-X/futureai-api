# 编辑器基本操作

[README.md](README.md) 第 4.2、4.3、5.9 步用 `vi` 编辑 `.env`，第 9.1 步用 `crontab -e` 打开定时任务、编辑器在那一步选定。本文是两者的按键速查，README 的操作步骤里只写保存退出的按键。

## 1 nano

nano 打开后，屏幕底部两行是它自己列出的快捷键提示，`^` 代表 `Ctrl` 键，例如 `^O 写入` 即按 `Ctrl+O` 保存。

保存与退出用到的按键如下：

| 按键 | 作用 |
|---|---|
| `Ctrl+O` | 写入（保存） |
| `Ctrl+X` | 退出；若有未保存的修改，会先问是否保存 |

提示 `File Name to Write:` 时直接回车，沿用原文件名。退出时若被问是否保存，按 `Y` 保存，按 `N` 放弃本次修改。

`Ctrl+O` 是保存，`Ctrl+X` 是退出，两者不要混淆。

移动光标用到的按键如下：

| 按键 | 作用 |
|---|---|
| 方向键、`PageUp`、`PageDown` | 上下左右移动、翻页 |
| `Ctrl+A`、`Ctrl+E` | 移到行首、行尾 |
| `Ctrl+_` | 跳到指定行号 |

编辑与查找用到的按键如下：

| 按键 | 作用 |
|---|---|
| `Ctrl+K` | 删除（剪切）当前整行；连续按可删除多行 |
| `Ctrl+U` | 粘贴最近一次剪切的内容 |
| `Ctrl+W` | 查找，回车确认；`Alt+W` 查找下一个 |
| `Ctrl+C` | 显示光标所在的行号与列号 |
| `Ctrl+G` | 打开联机帮助 |

删除整行用 `Ctrl+K`：光标停在该行任意位置即可，不必先选中整行。它执行的是剪切，删掉的内容会进入缓冲区，误删时按 `Ctrl+U` 可以还原。

## 2 vi

vi 与 nano 的主要差别是**模式**：打开后处于普通模式，此时直接敲字母不会插入文字，而是被当作命令执行。

进入与退出用到的按键如下：

| 按键 | 作用 |
|---|---|
| `i` | 进入插入模式，从光标处开始输入 |
| `Esc` | 回到普通模式 |
| `:wq` 加回车 | 保存并退出 |
| `:w` 加回车 | 保存，不退出 |
| `:q!` 加回车 | 不保存，强制退出 |

写 `:wq` 之前要先按 `Esc` 回到普通模式。若忘了按就直接敲，那几个字符会被当成插入的文字写进文件。

移动光标用到的按键如下：

| 按键 | 作用 |
|---|---|
| `h`、`j`、`k`、`l` | 左、下、上、右 |
| `0`、`$` | 行首、行尾 |
| `gg`、`G` | 文件开头、文件末尾 |
| `:<行号>` 加回车 | 跳到指定行 |

编辑与查找用到的按键如下：

| 按键 | 作用 |
|---|---|
| `dd` | 删除当前整行；`3dd` 删除三行 |
| `u` | 撤销 |
| `Ctrl+R` | 重做 |
| `/关键词` 加回车 | 向下查找；`n` 下一个，`N` 上一个 |
| `Ctrl+G` | 显示文件状态与光标位置 |
